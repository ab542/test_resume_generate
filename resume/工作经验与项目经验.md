## 自动化测试框架 - 问我 API 自动化测试框架

**项目定位** | 广告平台API自动化回归测试框架
-------|-------
**技术架构** | Pytest + Requests + 数据驱动 + YAML用例 + Allure/HTML双报告
**开发角色** | 独立设计开发

### 框架简介

为满足**问我（Digi Star）**项目频繁版本迭代的回归测试需求，独立设计开发了这套基于Pytest的数据驱动API自动化测试框架。框架采用**数据驱动测试**思想，所有测试用例以YAML格式定义，通用测试代码执行所有用例，新增用例无需修改Python代码，降低了自动化用例维护成本。

### 核心特性

- **YAML用例定义**：使用YAML格式编写测试用例，描述请求URL、方法、参数、预期结果，无需修改Python代码即可新增用例
- **变量替换支持**：YAML支持变量占位符，方便配置项目ID、用户ID等环境相关变量，本地配置覆盖不提交到Git
- **自动重试机制**：对5xx错误自动重试3次，避免网络波动导致的用例失败
- **响应时间统计**：自动收集统计各接口响应时间，按接口分类输出性能数据
- **异常自动检测**：自动检测响应中是否包含系统异常关键词，提前发现隐藏错误
- **登录复用**：Session级别的登录复用，Token缓存复用，无需每个测试用例重新登录
- **环境隔离**：支持开发/测试/预发布多环境切换，本地配置隔离敏感账号信息
- **双报告输出**：支持Allure美观测试报告和静态HTML报告，方便不同场景查看

### 成果价值

- 覆盖问我项目所有查询接口，实现核心业务接口回归测试自动化
- 大幅减少回归测试人力投入，回归测试效率提升60%+
- 及早发现代码改动引起的回归问题，降低线上缺陷逃逸概率
- 框架设计灵活，可扩展到其他项目使用

# AI 生成图片质量验收——怎么判断"符合预期"

---

## 核心问题

传统功能测试：输入 A → 期望输出 B，断言精确。  
AI 图片生成：输入「卧室 + 沙发」→ 期望「一张融合了卧室和沙发的图」，怎么断言？

**关键思路**：把"主观感受"拆成可检查的维度，每个维度定标准。

---

## 一、先定义"模板要求"具体指什么

面试时先说清楚你的理解：

> "符合模板预期不是一句模糊的话，我会先搞清楚需求方到底关注什么。通常拆成这几个维度——"

| 维度 | 含义 | 举例 |
|------|------|------|
| **结构合规** | 图片的构图、布局是否符合模板要求 | "人物必须在画面中央偏右，背景不能遮挡主体" |
| **元素完整** | 需求里提到的元素都出现了吗 | "沙发、落地灯、地毯这 3 样缺一不可" |
| **风格匹配** | 色调、画风、质感是否符合模板风格 | "要求二次元风格，如果出了写实风格就是不符合" |
| **比例正确** | 元素之间的大小比例是否合理 | "沙发不能比房间还大" |
| **无畸形/瑕疵** | 有无 AI 常见翻车 | 手指畸形、人脸扭曲、文字乱码、多余肢体 |

**面试金句**："我不跟 AI 说'好看'，我说结构、元素、风格、比例、瑕疵——每个都能检查。"

---

## 二、怎么量化验收——用 Checklist 代替主观感受

以「输入卧室模板图 + 沙发模板图 → 生成融合图」为例：

### 2.1 自动化可检查的（机器做）

```
检查项                          方法
──────────────────────────────────────────
图片是否生成成功              检查 HTTP 200 + 返回 URL 非空
图片格式是否正确              检查 Content-Type（image/png）
图片分辨率达标                读取宽高 ≥ 1024×1024
图片文件不为空/不纯黑/不纯白   像素采样，均值不在 0~5 或 250~255
是否有明显拼接痕迹            边缘检测算法，横向/纵向连续直线异常
局部重生成非选区是否不变      像素级 diff，变化率 < 5%
```

### 2.2 需要人工判断的（人做）

```
检查项                          怎么判断
──────────────────────────────────────────
元素是否齐全                    对照需求清单逐项勾：沙发 ✅ 落地灯 ✅ 地毯 ✅
风格是否匹配                    和模板图放一起对比，色调/笔触/光影一致
比例是否合理                    沙发尺寸 vs 房间尺寸，肉眼判断无违和感
细节无畸形                      放大看：人手、字体、对称结构有无 AI 常见错误
边缘过渡自然                    局部重生成区域和周围有没有明显分界线
```

**面试金句**："机器检查结构性的东西——有没有图、分辨率对不对、非选区变了没。人检查审美性的东西——风格对不对、元素全不全、有没有畸形。"

## 三、实际验收流程

```
生成一张图后，按这个顺序验收：

第1步：机器过一遍（秒级）
  → 有图？格式对？分辨率达标？非选区没变？
  → 任意一项 FAIL → 直接打回，不进入人工

第2步：结构检查
  → 对照需求清单，逐项勾「有没有」：沙发 ✅ 灯 ✅ 地毯 ❌
  → 缺少元素 → 记录「缺 XX 元素」

第3步：质量检查
  → 风格匹配？比例正常？无畸形？
  → 有问题 → 截图标注具体位置

第4步：打分
  → OK / Minor（有小瑕疵但可用）/ NG（不可用）
```

## 四、多轮生成怎么判断哪个更好

实际场景中 AI 可能生成 4 张候选图，需要选最优：

```
方法：加权打分表

        权重  图A  图B  图C  图D
元素完整  30%   5    4    5    3
风格匹配  25%   4    5    4    4
比例合理  20%   4    4    3    5
无畸形    15%   5    3    5    4
边缘过渡  10%   3    4    4    3
─────────────────────────────────
加权总分        4.3  4.1  4.3  3.7

结论：图A 和 图C 并列，选图A（无畸形分更高）
```

## 五、局部重生成怎么验收

局部重生成的核心验收标准是**选区外不变**：

```
测试方法：像素级对比

1. 取重生成前的图（Before）
2. 框选左上 1/4 区域 → 重生成 → 得到 After
3. 对 Before 和 After 做像素 diff：

     选区外（右下 3/4）：变化率应 < 5%
     选区内（左上 1/4）：应该变化

4. 重点看选区边界线：
     - 放大到像素级看边界有无明显接缝
     - 颜色/亮度在边界处是否平滑过渡
```

**面试金句**："局部重生成的验收标准就一条——选区外一个像素都不能变，选区边界不能有缝。这个可以自动化，不用每次人看。"

## 六、面试回答模板

如果面试官问「AI 生成的图片你怎么判断它是不是符合预期？」，直接这样回答：

> "我会分三步走。
>
> 第一步，先搞清楚需求方对'符合预期'的定义——是结构要对（东西放对位置）、元素要对（该有的都有）、还是风格要对（二次元不能变写实）。把模糊的预期拆成可检查的维度。
>
> 第二步，机器能检的交给机器——有没有图、分辨率对不对、格式对不对、局部重生成时非选区变了没。这些是硬指标，一票否决。
>
> 第三步，人检审美性的——风格、比例、畸形。我会做一个 checklist 逐项打勾，多张候选图用加权打分表选最优。
>
> 核心思路就是把主观变客观——不说'好不好看'，说'元素全不全、比例对不对、有没有畸形'。每一样都是可以明确判断的。"

## 七、提前准备的 Checklist 模板

面试时可以拿出来说「我会设计这样的打分表」：

```
========================================
图片 ID: __________    生成时间: __________
输入模板: __________ + __________ + __________
评审人: __________    评审时间: __________
========================================

【结构检查】（任一 FAIL → 直接打回）
□ 图片正常显示（非白屏/黑屏）
□ 分辨率 ≥ 1024×1024
□ 格式为 PNG/JPEG
□ 文件大小 > 10KB（排除空图）

【元素检查】（对照需求逐项勾）
需求元素清单:
  1. __________  □ 出现  □ 缺失  □ 位置不对
  2. __________  □ 出现  □ 缺失  □ 位置不对
  3. __________  □ 出现  □ 缺失  □ 位置不对
多余元素: □ 无  □ 有（说明: __________）

【质量检查】（1-很差  5-很好）
风格匹配度:  1  2  3  4  5
比例合理性:  1  2  3  4  5
细节无畸形:  1  2  3  4  5
（局部重生成时）边界过渡: 1  2  3  4  5
（局部重生成时）选区外不变: □ 是  □ 否 → 直接 FAIL

【最终判定】
□ OK（5 项全部 ≥ 4 分）
□ Minor（有 1~2 项 = 3 分）
□ NG（任一 ≤ 2 分 或 元素缺失）
```
